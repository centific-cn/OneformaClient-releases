# OneformaClient-releases

Public companion repo for **OneformaClient** desktop builds.

- **Download page (GitHub Pages):** [centific-cn.github.io/OneformaClient-releases/](https://centific-cn.github.io/OneformaClient-releases/)
- **GitHub Releases** here: modern on `latest-prod` / `latest-qa` / `latest-preuat` / `latest-uat`, legacy `legacy-v*` installers + updater manifests.
- **Legacy manual update feed**: `update-feed/legacy-latest-mac.json` and `legacy-latest-win.json` on `main` (written by CI).

Source code stays in private `centific-cn/OneformaClient`.

How to set up on Mac

Download the DMG

Use the button above to download the official disk image.

Install the app

Open the DMG and drag OneForma into the Applications folder.

Launch and sign in

Open OneForma from Applications and sign in with your OneForma account.

If macOS blocks the first launch, open System Settings → Privacy & Security and choose Open Anyway. For macOS 10.13–11, use a legacy build. Need Windows? Windows install guide.

Download channel

Internal channels stay selected in this browser until you choose Production again.

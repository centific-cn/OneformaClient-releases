OneForma

💻 Install on Mac

Download the app, move it into Applications, open it, and sign in.

✅ Use the release marked Latest. That row has a green Latest label and the title OneForma modern. Skip any row with a yellow Pre-release label. Those builds are for internal testing.

⬇️ Download for Mac

💿 Disk image on the Latest release (OneForma modern).

Release: github.com/centific-cn/OneformaClient-releases/releases/tag/latest-prod

  1. 1

    💿 Download

    Use the button above. It saves a disk image named OneForma-modern-<version>.dmg.

  2. 2

    📂 Move it to Applications

    Open the disk image. Drag OneForma onto the Applications folder.

  3. 3

    💻 Open OneForma

    Open OneForma from Applications. If macOS asks whether to open it, choose Open. If macOS says it cannot check the app, open System Settings → Privacy & Security, scroll to Security, click Open Anyway, and enter your Mac login password. You can eject the disk image after that.

  4. 4

    🔑 Sign in

    Sign in with your OneForma account.

🖥️ Older macOS

This download is for macOS 12 or later. For macOS 10.13 through 11, open the releases page and choose the release titled OneForma legacy. Leave Pre-release rows alone.

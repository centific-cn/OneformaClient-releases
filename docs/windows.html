OneForma

🪟 Install on Windows

Download the installer, run it, open OneForma, and sign in.

✅ After installing, sign in with your OneForma account. Once you see the signed-in home screen, the trial is working — nothing else to test.

⬇️ Download for Windows

💿 Installer on the latest release (OneForma-modern-<version>.exe).

Release: github.com/centific-cn/OneformaClient/releases/tag/qa-win-latest

  1. 1

    💿 Download

    Use the button above. It saves an installer named OneForma-modern-<version>.exe.

  2. 2

    ▶️ Run the installer

    Double-click the .exe file. The installer finishes on its own and OneForma starts afterwards. If Windows asks for permission to run, choose Yes.

  3. 3

    ⚠️ If Windows shows a blue "Windows protected your PC" screen

    The installer is not signed yet, so Windows may show this warning. It is expected for this trial build. Click More info, then click Run anyway.

  4. 4

    💻 Open OneForma

    If OneForma did not open by itself, open it from the Start menu or the desktop shortcut.

  5. 5

    🔑 Sign in

    Sign in with your OneForma account. When the home screen appears, you are done.

  1. 1

    Download the package, get your account

    • Download from the official page: https://centific-cn.github.io/OneformaClient-releases/windows.html — it opens on the QA channel and points at the public tag qa-win-manual. Save OneForma-modern-0.1.6.exe from there.
    • Account: self-applied — register at https://ch-qa-web.oneforma2.com/center/login and pick your own username and password. Then send the account name to the release owner: they add it to the verification-code whitelist and grant pilot permission. Release-owner accounts (e.g. uat1) are not distributed.
    • One account per person. Do not log into it from a phone or second PC during the run — devices kick each other out (90020).
    One package only countsA production-lookalike with the same file name and version exists. Never download by name from any other release or share — only use the official page above. Step 3 catches a wrong file.
  2. 2

    Check your machine

    reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion" /v EditionID
@("$env:LOCALAPPDATA\Programs\OneForma", "$env:APPDATA\OneForma") |
  ForEach-Object { "{0} => {1}" -f $_, (Test-Path $_) }
    • Edition — Professional / Enterprise / Education. Home (Core) → stop, results invalid.
    • Cleanliness — both paths print False and no OneForma keys exist. Anything found → screenshot, delete, re-run until clean. "Uninstalled before" ≠ clean.
    No Windows SandboxSandbox never shows the classic SmartScreen dialog — Step 6 would false-negative.

  3. 3

    Verify the package hash — veto gate

    (Get-FileHash "<path-to-package>\OneForma-modern-0.1.6.exe" -Algorithm SHA256).Hash -eq "B00DF328333D4A50C0E1B1D9C3D2F35DD608A33EF05CE2001F6E1F21FF7B77FA"

    The hash is the package's only identity. Screenshot: T1-hash-motw.png

    🔄 qa-win-manual is rolling — CI replaces the exe on every QA build. If the release owner announces a newer build, check against the sha256 in that tag's release notes instead.

    False → stop everythingA wrong file means the production lookalike or a tampered copy. Report to the release owner; do not install.
  4. 4

    Keep the "download mark" (MOTW)

    Get-Item "<path>\OneForma-modern-0.1.6.exe" -Stream Zone.Identifier

    Stream content listed → done. Error "stream does not exist" → the transfer stripped it. Restore:

    Add-Content -Path "<path>\OneForma-modern-0.1.6.exe" -Stream Zone.Identifier -Value "[ZoneTransfer]","ZoneId=3"
    Why it mattersWithout this mark Step 6's SmartScreen dialog never appears — a guaranteed false "pass".
  5. 5

    Start the evidence recorder

    $T = "$env:USERPROFILE\Desktop\qa-test-<yourname>-<YYYYMMDD>"
New-Item -ItemType Directory -Path $T -Force | Out-Null
Start-Transcript -Path "$T\transcript.txt"

    All screenshots go into this folder. Keep the window open until the very end — it records every command you run. On a VM, also take a snapshot now.

  9. 9

    In-app checks

    • About shows 0.1.6 — Help → About OneForma. Publisher = Centific.
    • Tag card (pilot only) — first click opens the consent drawer; after consenting, it opens directly. Stay on this machine afterwards.
    • Watermark (pilot only) — inside the Tag tab, diagonal watermark with device ID + timestamp.
    • New tab blocking — chatgpt.com → "Access Blocked" dialog; www.baidu.com opens normally.
    • Copy / paste (pilot only) — Ctrl+C works in the Tag tab; Ctrl+V paste is blocked.
    • Check for Updates fails — profile menu → Check for Updates. A failure error is expected.

    One screenshot per item — file names in the manual §7.

    No Tag card on Home?Expected for a non-pilot account — server-side gating, not a bug. Mark the pilot-only items N/A - non-pilot account and continue. Pilot accounts are not distributed; use your own applied QA account.
    Update found / downloading?That is the wrong-channel package. Screenshot, stop, report.
